# Luxora Perfumes

A full stack perfume commerce application built with Next.js, React, TypeScript, Drizzle ORM, PostgreSQL, Cloudinary, and Tailwind CSS.

Luxora Perfumes is designed as a modern product-focused commerce project. It demonstrates frontend product experience, database-backed workflows, image management, admin integration planning, and modern full stack architecture.

## Available Scripts


```bash
bun dev
```

### Build Production App

```bash

```

### Start Production Server


## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/MustafaKheda/luxora-perfumes.git
cd luxora-perfumes
```

### 2. Install Dependencies

```bash
npm install
```

or

```bash
bun install
```

### 3. Configure Environment Variables

Create a `.env` file and add your database and Cloudinary configuration.

Example:

```env
DATABASE_URL=postgresql://user:password@localhost:5432/luxora
CLOUDINARY_CLOUD_NAME=your-cloud-name
CLOUDINARY_API_KEY=your-api-key
CLOUDINARY_API_SECRET=your-api-secret
```

### 4. Push Database Schema

```bash
npm run db:push
```

### 5. Seed Database

```bash
npm run db:seed
```

### 6. Start the App

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
